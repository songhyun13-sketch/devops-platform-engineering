# Publication boundaries and security

Public material consists of generalized descriptions, aggregate metrics and SHA-256 prefixes of supporting evidence; private raw sources are deliberately excluded. This repository contains documentation and illustrative configuration examples.

- Do not copy raw execution logs, unredacted manifests, private credentials, network addresses, service identity details or personal filesystem locations.
- Do not publish production source, recovery scripts, internal operating instructions or internal operational identifiers.
- Tie architectural and failure-injection statements to a single documented run and its time.
- Concept examples under examples/ are illustrative.
- Review every new attachment, diagram and revision through the same redaction and evidence check before any future public release.

The original evidence is retained privately; only bounded source type, selected values, recording time and SHA-256 prefix appear in the evidence summaries.
