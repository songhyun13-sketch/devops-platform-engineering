# Publication boundaries and security

Public material consists of generalized descriptions, aggregate metrics and SHA-256 prefixes of supporting evidence; private raw sources are deliberately excluded. This repository contains documentation and illustrative configuration examples, not executable service deployment logic.

- Do not copy raw execution logs, unredacted manifests, private credentials, network addresses, service identity details or personal filesystem locations.
- Do not publish production source, recovery scripts, worker coordination instructions or internal operational identifiers.
- Keep architectural and failure-injection claims tied to a single documented run; cross-environment integration is not implied.
- Concept examples under examples/ are illustrative and are not intended to be deployed.
- Review every new attachment, diagram and revision through the same redaction and evidence check before any future public release.

The original evidence is retained privately; only bounded source type, selected values, recording time and SHA-256 prefix appear in the evidence summaries.
